# Solid Feather

A Solid 2 port of the [Feather icons](https://feathericons.com/) collection.

This project is based on the [React Feather project](https://github.com/feathericons/react-feather).

## Usage
Put this in your `package.json`:
```
{
  "dependencies": {
    "solid-feather": "github:repr-man/solid-feather"
  }
}
```
